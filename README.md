\# OpenWeather Weather App



A simple Python Weather Application using the OpenWeather API.



\## Features



\- Search weather by city name

\- Display current temperature

\- Display feels-like temperature

\- Display humidity

\- Display weather condition

\- Display wind speed

\- Handles invalid city names

\- Handles API errors



\## Technologies Used



\- Python

\- Requests

\- OpenWeather API

\- JSON
